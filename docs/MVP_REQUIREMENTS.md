# 小商家海报平台 MVP 需求

## 产品目标

帮助行业分散的小商家在 3 分钟内完成一张朋友圈促销海报并下载 PNG 或 JPG 文件。

## 目标用户

- 商家用户：不会专业设计，需要快速制作促销海报。
- 平台管理员：制作和发布模板，维护模板分类与素材。
- 团队成员：根据授权查看或编辑商家的设计稿。

## 核心指标

- 首批 3 至 5 个真实商家完成试用。
- 至少 80% 的试用用户在 3 分钟内完成首次出图。
- 首次制作不需要开发人员代替操作。
- 已保存设计稿可以重新打开并保持视觉内容一致。

## 页面范围

### 商家端

1. 登录页：手机号验证码或微信登录入口。
2. 模板中心：分类、封面、名称和模板预览。
3. 模板填写页：展示模板预览和允许修改的字段表单。
4. 图片处理：上传、替换和基础裁剪。
5. 设计列表：草稿、已完成设计和最近更新时间。
6. 设计详情：继续编辑、复制和删除。
7. 导出页：选择 PNG/JPG、预览和下载。

### 管理端

1. 模板列表：草稿、已发布、已停用状态。
2. 模板编辑器：添加和调整文字、图片、矩形元素。
3. 字段配置：把元素标记为文本、图片、价格、日期或联系方式字段。
4. 模板发布：校验字段、生成封面并发布。
5. 素材管理：上传、分类、停用和删除素材。

## 业务规则

### 登录

- 未登录用户可以浏览模板。
- 保存设计稿、上传素材和导出前必须登录。
- MVP 代码先实现可替换的手机号登录接口，微信登录通过独立适配器后续接入。

### 模板

- 模板状态为 `DRAFT`、`PUBLISHED` 或 `DISABLED`。
- 商家只能使用 `PUBLISHED` 模板。
- 已被使用的模板停用后不影响历史设计稿。
- 模板字段键在同一模板内唯一。
- 发布模板前必须校验所有字段与元素引用。

### 设计稿

- 从模板创建时复制模板 JSON，后续模板更新不自动修改已有设计稿。
- 设计稿状态为 `DRAFT`、`ACTIVE` 或 `DELETED`。
- 每次成功保存生成不可变版本。
- 保存请求必须携带当前基础版本号。
- 版本冲突时拒绝覆盖并提示重新加载。

### 权限

- `OWNER` 可以编辑、授权、删除和导出。
- `EDITOR` 可以编辑和导出，不能变更所有者。
- `VIEWER` 只能查看和下载已有导出文件。
- 平台管理员可以管理模板，不能默认查看商家私有设计稿。

### 素材

- 允许 JPEG、PNG 和 WebP。
- 单文件默认上限为 10 MB。
- 文件扩展名、MIME 类型和文件魔数必须一致。
- 文件存储在 MinIO，数据库只保存对象键与元数据。

### 导出

- MVP 支持 PNG 和 JPG。
- 第一阶段由浏览器导出并下载。
- 后续服务端导出使用异步任务，状态为 `PENDING`、`PROCESSING`、`SUCCEEDED` 或 `FAILED`。

## 关键验收场景

1. 商家登录后可以从已发布模板创建一份独立设计稿。
2. 商家只能提交模板声明过的字段。
3. 缺少必填字段时保存失败并指出具体字段。
4. 商家上传有效图片后可以在模板中预览。
5. 使用旧版本号保存时返回 409，现有数据保持不变。
6. 其他租户成员无法通过猜测 ID 读取设计稿。
7. 设计稿保存后重新打开，JSON 与最后成功版本一致。
8. 浏览器导出的图片尺寸与模板画布尺寸一致。

## 非 MVP 范围

- 商家自由添加任意元素。
- 多人实时光标和冲突合并。
- AI 生成图片或模板。
- PDF、视频和动画导出。
- 直接发布到微信朋友圈。
- 订阅计费、印刷下单和组件市场。
